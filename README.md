# WPS 工程表清理助手

注：本项目主要由 AI 辅助开发，并经过实际工程表格持续测试和迭代。不同 WPS 版本可能存在兼容性差异，请先在文件副本中测试。

一个面向 **WPS 表格（Windows）** 的 JSA / XLAM 工程表辅助插件。

当前版本：**v1.9.2**

> 本项目主要用于工程造价、工程量清单、概预算、人材机汇总表等表格的批量整理与检查。

别的表格应该也行，请自行测试。
因为领导的神秘要求从而诞生的本插件（笑）

## 主要功能

- 删除完全空白行
- 按指定列为空删除行
- 清除匹配文字内容（不删除行列）
- 中文大项同名同号
- 数字序号顺位
- 清理短尾页表头
- 调整打印范围与分页线
- PDF 导出文字/打印风险检测
- 统一表格外框与内部线宽
- 批量删除工作表
- 全部工作表分页预览 / 普通视图
- 诊断中心：工程表体检、分页诊断、PDF 风险、表格线宽诊断、序号层级诊断

## v1.9.2 重点

- 修复 `工程名称 / 项目名称` 等横向合并说明行被误识别为新表标题的问题。
- 修复 `合计 / 总计 / 小计 / 累计` 等表尾汇总行被误识别为新表标题的问题。
- 连续宽标题候选折叠为同一“表头组”，只在真正的后续独立表格起点前建立手动分页。
- 分页诊断明确区分 WPS 自动分页与插件期望手动分页，减少蓝色分页线误判。
- 各项诊断均提供“当前工作表 / 整个工作簿”两种范围。

普通用户建议直接从 **GitHub Releases** 下载最新版：

https://github.com/lyouroboros109/wps-engineering-table-cleaner/releases/latest

不要直接下载 `src` 目录来安装。

## 安装

1. 下载 `工程表清理助手_v1.9.2.xlam`。
2. 打开 WPS 表格。
3. 进入 **工具 → 加载项**。
4. 点击浏览并选择 `.xlam` 文件。
5. 勾选加载项并确认。
6. 重新打开 WPS 后，在顶部功能区寻找 **工程表清理**。

升级旧版时请先取消勾选旧版加载项并彻底关闭 WPS，避免多个版本同时加载。

详细说明见：

- `docs/INSTALL.txt`

## 使用前提示

建议首次使用任何批量删除或结构调整功能时：

1. 先保存原始文件副本；
2. 在副本上测试；
3. 检查分页预览和打印预览；
4. 再处理正式文件。

不同 WPS 版本对 JSA、分页符、合并单元格边框等接口的行为可能存在差异。WPS 自动分页还会受到纸张、打印机驱动、行高、缩放和页边距影响。
