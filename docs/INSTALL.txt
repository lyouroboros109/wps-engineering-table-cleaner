WPS 工程表清理助手 v1.9.2 升级说明

本版继续修复分页蓝线上下边界，并重做诊断中心入口。

一、本次截图的分页根因
- “措施项目计算汇总表”第14行是横向合并的“合 计”。
- v1.9.1 诊断显示“宽表名候选行：1、14；独立表头组起点：1、14；插件期望分页：14”。
- 因而插件把表尾合计行误当成第二张表的标题，在第14行前插入手动分页，造成正文为第1页、合计单独成为第2页。

二、v1.9.2分页修复
- 宽表名判断改用去空格后的有效文本长度，避免“合 计”靠空格凑够标题长度。
- 明确排除“合计、总计、小计、累计、本页合计”等纯汇总标签。
- 不会排除“措施项目计算汇总表”这种真正的标题。
- 分页诊断明确区分：WPS自动分页（正常）与插件期望手动分页。自动分页不再被误判为“额外分页”。
- 对本次表格，重建后的期望手动分页应为“无”，第14行手动蓝线应被清除，整张短表应回到1页。

三、诊断中心重排
“诊断中心”中以下功能全部单独显示，并都提供【当前工作表 / 整个工作簿】：
- 工程表体检
- 分页诊断
- PDF风险
- 表格线宽诊断
- 序号层级诊断

四、整本诊断报告
- 分页诊断：每张表汇总PrintArea、实际Row.PageBreak、HPageBreaks、宽表名候选、表头组、期望手动分页和异常结论。
- 线宽诊断：逐表、逐表格块输出边框核验结果。
- 序号层级诊断：逐表输出数字层级和中文大项判断。
- PDF风险原本已支持整本，本版保留。

安装 / 升级：
1. 先取消勾选旧版加载项，并彻底关闭 WPS。
2. 重新打开 WPS 表格，进入 工具 → 加载项。
3. 浏览并选择“工程表清理助手_v1.9.2.xlam”。
4. 勾选加载项并确认。
5. 不要同时加载多个版本。
6. 首次请在文件副本中测试。

建议：安装后先对当前“措施项目计算汇总表”执行【打印范围与分页线 → 自动重建：当前工作表】，再执行【分页诊断 → 当前工作表】。期望结果：宽表名候选仅第1行、期望手动分页为无、Row.PageBreak不再出现第14行手动分页。
