# 如何公开分享给其他人

## 推荐方式：GitHub 仓库 + Releases

仓库用于公开：

- 源代码
- README
- 安装说明
- 更新日志
- Bug 反馈

GitHub Releases 用于公开：

- `.xlam` 可安装文件
- 完整 `.zip` 安装包

这样普通用户不需要理解源码，只需进入 Releases 下载。

## 首次发布步骤

1. 确认仓库 Visibility 为 `Public`。
2. 把 `repository` 文件夹里的内容上传到仓库根目录。
3. 提交 Commit。
4. 打开仓库右侧的 **Releases**。
5. 点击 **Create a new release**。
6. Tag 填：`v1.8.0`
7. Release title 填：`工程表清理助手 v1.8.0`
8. Release notes 可以复制 `RELEASE_NOTES_v1.8.0.md`。
9. 上传 `release-assets` 文件夹里的：
   - 工程表清理助手_v1.8.0.xlam
   - WPS工程表清理助手_v1.8.0.zip
10. 点击 **Publish release**。

## 分享给别人

发布完成后，最推荐分享：

- 仓库主页：适合开发者、查看说明和反馈 Bug
- Releases 页面：适合普通用户下载

不要只把源码页面发给普通用户，否则他们可能不知道应该下载哪个文件。

## 关于许可证

公开仓库不等于自动允许别人修改、转载或重新发布源码。

如果希望项目真正开源，建议明确添加许可证。

### MIT

适合：
- 希望传播范围大
- 允许别人修改、商用、再发布
- 只要求保留版权和许可证声明

### GPL-3.0

适合：
- 允许别人使用和修改
- 但希望衍生项目继续以 GPL 方式公开源码

在决定前，不要随意把许可证文本当成形式文件。
